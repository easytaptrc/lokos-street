# Territorio Lokos Street — sitio web

Sitio estático: no necesita servidor ni instalación.

- `index.html` — página de inicio
- `menu.html` — menú completo con buscador y "Mi pedido"
- `Menu_Territorio_Lokos_Street.pdf` — menú para imprimir (también se descarga desde la web)
- `imprimir/menu-imprimible.html` — fuente del PDF (ábrelo en Chrome y usa Imprimir → Guardar como PDF, tamaño carta, sin márgenes)
- `assets/js/data.js` — **aquí se editan precios, descripciones y datos de contacto** (dirección, horario, teléfono, WhatsApp, Facebook, Maps)

## Publicar con GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio de GitHub (los archivos deben quedar en la raíz del repositorio, con `index.html` al primer nivel).
2. En el repositorio entra a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En un par de minutos el sitio queda en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.
